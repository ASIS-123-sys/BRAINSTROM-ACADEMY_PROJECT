# Brainstorm Academy — Web Application

Brainstorm Academy is a coaching institute based in Berhampur, Ganjam offering computer courses, 12th grade coaching, and classes for 5th to 10th standard students. This web application was built to bring the institute online — giving students, faculty, and the admin a single platform to manage everything from academics to fees.

The app has three sections. The public landing page shows courses, faculty, notices, photo gallery, and contact details. The student portal lets students log in with their enrollment ID to check their marks, view score graphs, and track fee payments. The admin panel gives the institute full control to manage students, faculty, courses, notices, and the photo gallery.

Built with Next.js and Tailwind CSS on the frontend, Supabase for the database and authentication, and deployed on Vercel.
